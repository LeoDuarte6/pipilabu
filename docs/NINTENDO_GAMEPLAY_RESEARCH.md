# Nintendo Gameplay Research Applied to Doge Apple Shop

## Working principles

1. Start with the action, not the character art. The player's repeated work must be enjoyable before the final Doge rig exists.
2. Repetition should create mastery. A second timed run should improve because players learned positioning and rhythm.
3. Teach one element at a time through staging. Add color, treatment, urgency, and surprises in separate gates.
4. Give the most frequent action the richest feedback. Apple handoff deserves the clearest animation, customer reaction, HUD pulse, original sound, and controller vibration.
5. Expand by multiplying trusted rules: `apple color × treatment × condition × customer temperament`.
6. Add surprise only after normal rules are legible.
7. Make cooperation generous without enabling sabotage outside explicitly competitive events.
