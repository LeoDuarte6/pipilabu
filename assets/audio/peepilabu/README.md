# Peepilabu prototype voice pack

Five normalized mono clips were cut from `assets/reference/peepilabu-market-reference.mp4`:

- three high-pitched baby-customer `Peepilabu` reactions for successful handoffs;
- two player/shopkeeper `What the dog doing?` callouts for a future explicit interaction.

`wav/` contains 48 kHz PCM editing masters. `ogg/` contains compact game-ready previews. Exact source timestamps, processing, categories, and playback rules live in `manifest.json`.

Use a shuffle bag for baby reactions so every clip plays once before refilling and the immediately previous clip cannot repeat. Keep playback-speed variation restrained (`0.97` to `1.05`); the source performances already provide character.

These files are a private prototype/reference pack. Do not upload them to Roblox or ship them publicly until the team has cleared the source or replaced them with original performances that preserve the same cadence and emotional role.
